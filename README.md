This is a disorganized collection of mathematical proofs that I find
interesting. The proofs are usually transcribed from one or more sources (books,
Wikipedia, university courses, ...) with my additional personal tweaks.

The proofs are written by hand, then scanned and processed by an LLM to convert
them to LaTeX.

If you find any mistakes or want to suggest improvements, feel free to send me
an email or open a [PR](https://github.com/0xHaru/proofs/pulls)!

The rendered PDFs are available at
[0xharu.github.io/proofs](https://0xharu.github.io/proofs).
